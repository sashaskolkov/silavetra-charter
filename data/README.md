# База яхт

Фундамент для сайта бронирования. Схема — из файла «Яхты бронирование.xlsx»,
колонки повторены один в один.

| Файл | Что это |
| --- | --- |
| `yachts.xlsx` | основная таблица, 140 лодок, фильтр и закреплённая шапка |
| `yachts.csv` | тот же набор в UTF-8 — им удобно кормить код и смотреть диффы в git |
| `generate.py` | генератор, зерно фиксировано: перезапуск даёт тот же результат |
| `photos.source.json` | 35 ссылок с Викисклада с авторами и лицензиями |
| `PHOTO-CREDITS.md` | кому что принадлежит |

**Данные вымышленные.** Реальны только названия регионов, портов, моделей лодок
и ссылки на фотографии. Цены, названия судов и характеристики придуманы.

## Колонки

| Колонка | Тип | Примечание |
| --- | --- | --- |
| Название | текст | уникально по всей таблице |
| Тип Яхты | текст | модель; длина — свойство модели |
| Команда | `Капитан` / `Капитан и помощник` | экипаж входит в стоимость |
| Добавить повара | `Да` / `Нет` | **не услуга, а признак лодки** — см. ниже |
| Регион, Порт | текст | 40 пар, порт у региона всегда один |
| Каюты | число | |
| Длина | текст `«N м»` | формат из исходной таблицы |
| Места для гостей | число | без экипажа |
| Туалет | число или `Нет` | у лодок короче 12 м гальюна может не быть |
| Стоимость за день | число, ₽ | |
| Состояние | 3–5 | |
| Фото | ссылка | в xlsx — кликабельная, в csv — голый URL |

## Правила, зашитые в данные

- **Добавить повара** — это галка, которую можно поставить при выборе лодки,
  и доступна она **от 12 метров**: ниже нет ни камбуза, ни места для человека.
  На всех 140 строках правило не нарушается ни разу, проверено.
- **Помощник** обязателен от 14 метров. На лодках меньше встречается у сложных
  классических корпусов — как у десятиметровой «Белой ночи» из исходной таблицы.
- **Гостей ≈ 0.62 на метр длины**, кают — около половины числа гостей.
  Коэффициент снят с ваших строк: 9 м / 6 гостей, 15 м / 10, 28 м / 16.
- **Цена** = гости × (2200 + состояние×200 + длина×25) × региональный коэффициент,
  округление до 500 ₽. На эталонных размерах формула даёт 15–64 тыс. ₽ — то есть
  попадает в ваши числа.
- **Региональный коэффициент** — логистика: Азов и Каспий 0.80–0.90,
  Балтика и Чёрное море около 1.0, Арктика и Командоры 1.35–1.60.

## Шесть строк из исходного файла

«Белая ночь», «Морти», «Liberty», «Яхта», «Рик», «Iron Lady» перенесены
**дословно**, включая совпадающие характеристики «Морти» и «Рика» и лодку
с названием «Яхта». Они служат эталоном, по ним откалиброваны формулы.

## Что стоит решить до боевого использования

- Крымское побережье в список не вошло — статус спорный, и вшивать его
  в данные молча не хотелось. Если для теста нужно, добавляется в `REGIONS`.
- Фотографии соответствия лодкам не имеют — раздавались по кругу.
- Часть кадров под CC BY-SA: при публикации нужно видимое указание авторства.
