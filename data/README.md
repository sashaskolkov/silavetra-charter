# База яхт

Фундамент для сайта бронирования. Схема — из файла «Яхты бронирование.xlsx»,
колонки повторены один в один.

| Файл | Что это |
| --- | --- |
| `yachts.xlsx` | основная таблица, 140 лодок, фильтр и закреплённая шапка |
| `yachts.csv` | тот же набор в UTF-8 — им удобно кормить код и смотреть диффы в git |
| `generate.py` | генератор, зерно фиксировано: перезапуск даёт тот же результат |
| `geography.py` | карта «акватория → большой регион и порт» |
| `expansion.py` | генератор флота на реках, водохранилищах и больших озёрах |
| `expansion.csv` | 109 лодок расширения — своё зерно, чтобы не двигать `yachts.csv` |
| `build-fleet.py` | собирает `fleet.csv` — то, что читает сайт |
| `fleet.csv` | 284 лодки: 140 из таблицы, 109 расширения, 35 своих |
| `geography.json` | порядок регионов с запада на восток, для сайта |
| `find-photos.py` | собирает фотопул чартерных яхт с searadar.com |
| `photos.source.json` | 166 кадров с моделью, лодкой и источником |
| `photos.themes.json` | какие кадры к какому семейству верфи относятся |
| `PHOTO-CREDITS.md` | кому что принадлежит |

## Два уровня географии

Исходная таблица знает только «Регион», и там лежат **акватории**: Темрюкский
залив, Залив Терпения, Цемесская бухта. Искать по ним нельзя — человек выбирает
не Темрюкский залив, а Азовское море. Поэтому `build-fleet.py` раскладывает
исходный «Регион» на три поля по карте из `geography.py`:

| Уровень | Пример | Где виден |
| --- | --- | --- |
| Регион | Карелия | поиск круизных и моторных лодок |
| Акватория | Ладожское озеро | карточка лодки |
| Порт | Сортавала | карточка лодки |

**Спортивные лодки ищутся по городу, а не по региону**: они стоят на восьми
базах «Силы ветра» и никуда с них не уходят. Регион у них в базе есть, но
в поиске не участвует.

Правило распределения — водный бассейн, а не административная граница. Поэтому
всё Белое море уходит в Карелию, хотя часть его берегов архангельские, а Мурманск
на Кольском заливе относится к Арктике, хотя Мончегорск в той же области —
к карельским озёрам. По той же причине Братское море попадает в Енисей: оно
стоит на Ангаре, а она приток Енисея.

Сейчас в базе **18 регионов и 72 акватории**. Крымское побережье в них не входит
(см. ниже).

## Почему расширение отдельным файлом

`generate.py` собирает `yachts.csv` с фиксированным зерном: перезапуск даёт тот
же результат. Обратная сторона — **добавь в его список направлений одну строку,
и сдвинется вся последовательность случайных чисел**, после чего перегенерируются
все сто сорок лодок. Записи, на которые уже ссылаются страницы сайта, поменяли бы
модель, цену и порт без всякой причины.

Поэтому новые регионы живут в `expansion.py` со своим зерном. Формулы он берёт
из `generate.py` — цена, гости, каюты и экипаж считаются ровно так же, — но
исходную таблицу не трогает. `build-fleet.py` читает оба файла и складывает
в `fleet.csv`.

## Фотографии: три захода и один вывод

Кадры лодкам подбирает `build-fleet.py`, пул собирает `find-photos.py`.
Правильный источник нашёлся не сразу, и обе неудачи стоят того, чтобы их знать.

**Заход первый — по географии.** Пул набирался по категориям Викисклада
«Байкал», «Чёрное море», «Камчатка»: логика «лодке её море». Но категория места
по определению отдаёт пейзаж, и в каталоге оказались сотни снимков воды
без единой яхты в кадре.

**Заход второй — по верфям на Викискладе.** Уже лодки, но не те. Запросы
«wooden / vintage / classic yacht» вытянули архив начала XX века: чёрно-белую
Сиднейскую гавань, гафельные шхуны и один броненосец. Причина в том, что
свободных лицензий на современную чартерную съёмку почти нет — её снимают
верфи и брокеры, и в общий доступ она не попадает.

**Заход третий — чартерный каталог.** Берём оттуда, где такая съёмка и живёт:
`searadar.com`. У него в адресе картинки зашита модель лодки, а размер кропа —
часть пути, поэтому те же кадры отдаются в 1600×900:

```
.../crop/1600/900/a40/b3/39212-1615826-bavaria-cruiser-32-lila.jpeg
                         ^лодка ^фото  ^модель            ^имя
```

Тип лодки берётся из параметра поиска, а не угадывается по имени файла:
`2` — парусные, `3` — катамараны, `4` — моторные. Без этого «Aquila 32 Sport»
и надувной «3D Tender» попадали в круизные парусники. Длина фильтруется
по числу в названии модели — от 25 до 55 футов.

Из листинга берётся первый кадр каждой лодки: он почти всегда экстерьер,
дальше идут камбуз и каюты.

**Вывод:** ось подбора — модель лодки, а не место. Человек смотрит на карточку,
чтобы увидеть лодку. Bavaria Cruiser 46 получает кадр «Баварии», Lagoon —
катамаран, Princess — моторную. Советские корпуса вроде «Конрада» своей съёмки
не имеют и берут любой круизный парусник близкого размера.

Скачанные кадры пережимаются до 1200 пикселей по длинной стороне:
из каталога они приходят по мегабайту, а карточке столько не нужно.
Список — в `PHOTO-CREDITS.md`.

**Данные вымышленные.** Реальны только названия регионов, портов, моделей лодок
и ссылки на фотографии. Цены, названия судов и характеристики придуманы.

## Колонки

| Колонка | Тип | Примечание |
| --- | --- | --- |
| Название | текст | уникально по всей таблице |
| Тип Яхты | текст | модель; длина — свойство модели |
| Команда | `Капитан` / `Капитан и помощник` | экипаж входит в стоимость |
| Добавить повара | `Да` / `Нет` | **не услуга, а признак лодки** — см. ниже |
| Регион, Порт | текст | 40 пар; здесь «регион» — это акватория, см. выше |
| Каюты | число | |
| Длина | текст `«N м»` | формат из исходной таблицы |
| Места для гостей | число | без экипажа |
| Туалет | число или `Нет` | у лодок короче 12 м гальюна может не быть |
| Стоимость за день | число, ₽ | |
| Состояние | 3–5 | |
| Фото | ссылка | в xlsx — кликабельная, в csv — голый URL |

## Правила, зашитые в данные

- **Добавить повара** — это галка, которую можно поставить при выборе лодки,
  и доступна она **от 12 метров**: ниже нет ни камбуза, ни места для человека.
  На всех 140 строках правило не нарушается ни разу, проверено.
- **Помощник** обязателен от 14 метров. На лодках меньше встречается у сложных
  классических корпусов — как у десятиметровой «Белой ночи» из исходной таблицы.
- **Гостей ≈ 0.62 на метр длины**, кают — около половины числа гостей.
  Коэффициент снят с ваших строк: 9 м / 6 гостей, 15 м / 10, 28 м / 16.
- **Цена** = гости × (2200 + состояние×200 + длина×25) × региональный коэффициент,
  округление до 500 ₽. На эталонных размерах формула даёт 15–64 тыс. ₽ — то есть
  попадает в ваши числа.
- **Региональный коэффициент** — логистика: Азов и Каспий 0.80–0.90,
  Балтика и Чёрное море около 1.0, Арктика и Командоры 1.35–1.60.

## Шесть строк из исходного файла

«Белая ночь», «Морти», «Liberty», «Яхта», «Рик», «Iron Lady» перенесены
**дословно**, включая совпадающие характеристики «Морти» и «Рика» и лодку
с названием «Яхта». Они служат эталоном, по ним откалиброваны формулы.

## Что стоит решить до боевого использования

- Крымское побережье в список не вошло — статус спорный, и вшивать его
  в данные молча не хотелось. Если для теста нужно, добавляется в `REGIONS`.
- Фотографии подбираются по региону, но не по конкретной лодке: на карточке
  байкальской яхты будет Байкал, однако не эта яхта.
- Часть кадров под CC BY-SA: при публикации нужно видимое указание авторства.
- У Байкала нет своего кадра: пять лодок стоят на общей фотографии из флота.
- Мончегорск на Имандре заказчик относит к Карелии, но лодок там пока нет —
  акватория появится, когда появится флот.
