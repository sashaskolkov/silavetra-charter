# ProjectTest — тестовая песочница

Это **тестовый проект для упражнений и тренировок**. Здесь нет боевого кода и заказчиков — можно свободно экспериментировать, ломать и переделывать.

## Правила работы здесь

- Всё в этом репозитории — учебное. Ошибки допустимы и даже полезны: на них тренируемся.
- Эксперименты складываем в `experiments/` — по подпапке на упражнение (`experiments/<название>/`).
- Заметки, выводы и «что поняли из упражнения» — в `notes/`.
- Коммитим по завершении упражнения, чтобы историю тренировок было видно в git log.
- Никаких секретов, токенов и реальных данных команды сюда не кладём.

## Структура

```
ProjectTest/
├── CLAUDE.md        # этот файл — контекст проекта
├── README.md        # описание для человека
├── experiments/     # упражнения, по папке на каждое
└── notes/           # заметки и выводы по тренировкам
```
